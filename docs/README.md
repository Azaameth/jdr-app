# Documentation

Ce dossier existe pour la convention de chemin de spec-kitty (mission
software-dev). La documentation du projet vit à la racine :

- `README.md` — présentation, commandes, workflow spec-kitty
- `CLAUDE.md` — conventions de code et contexte de migration
- `MIGRATION_BACKLOG.md` — état de la migration depuis le monolithe legacy
- `NEXTSTEPS.md` — registre d'incréments des missions en cours
- `legacy-reference/README.md` — index de la référence comportementale legacy
- `kitty-specs/` — specs, plans et artefacts des missions
