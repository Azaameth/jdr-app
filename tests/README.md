# Tests

Ce dépôt ne centralise pas ses tests ici — ce dossier existe pour la convention
de chemin de spec-kitty (mission software-dev).

Emplacements réels :

- **Tests unitaires (Vitest)** : co-localisés avec le code dans `src/**/__tests__/`
  (`npm run test:unit`)
- **Tests end-to-end (Playwright)** : `e2e/` (`npm run test:e2e`)
